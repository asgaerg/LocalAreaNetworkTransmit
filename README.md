# 局域网资源传输服务器（LocalAreaNetworkTransmit）

一个基于 **Node.js + Express** 的极简局域网文件共享/下载服务器。

启动后，同一局域网内的任意设备（手机、平板、其他电脑）打开浏览器，即可访问并下载你电脑桌面上的文件——不用装任何客户端、不用数据线、不用微信传文件。

## 功能

| 地址 | 作用 |
|---|---|
| `http://<本机IP>:3000/soure/` | 浏览并下载**桌面文件夹**中的所有文件（静态目录） |
| `http://<本机IP>:3000/download?name=文件名` | 下载桌面上的指定文件 |
| `http://<本机IP>:3000/book?name=文件名` | 下载小说目录中的指定文件 |

## 特点

- **零配置**：启动时自动识别本机局域网 IP 并打印访问地址（支持「本地连接 / WLAN / 以太网」多种网络接口）；
- **不写死个人路径**：通过 `os.userInfo().username` 动态获取当前系统用户名，换台电脑拉下来就能直接跑；
- **依赖极简**：只需要 Express。

## 使用方法

```bash
# 1. 安装依赖
npm install

# 2. 启动服务
node app.js

# 3. 按控制台提示访问，例如：
#    服务开启在 192.168.x.x:3000
#    静态资源地址 192.168.x.x:3000/soure/
```

## 目录约定

- 默认分享目录：**当前用户的桌面**（`C:/Users/<用户名>/Desktop`）；
- 小说下载目录：`C:/Users/<用户名>/Desktop/小说后端服务器/book/static/book/`；
- 想分享其他目录，改 `app.js` 里对应的路径即可。

## ⚠️ 安全提示（重要）

- 本服务**没有任何鉴权机制**，局域网内任何设备都能访问你分享的目录；
- 仅建议在**可信的家庭/办公局域网**里临时使用，传完文件随手关掉（`Ctrl+C`）；
- **不要**把它暴露到公网（不要做端口映射或内网穿透）；
- 分享的目录里只放需要传输的文件，避免把私密资料放在桌面根目录。
